## Project Overview
This project is a Python-based Object-Oriented Programming (OOP) system designed to manage students and courses in an academic environment. It utilizes custom classes, instance methods, class methods, and advanced Python data structures (dictionaries and tuples).

---

## Alignment with Digital Public Goods (DPG) Standards

This solution aligns with DPG principles in the following ways:
1. **Open-Source**: The source code is publicly hosted on GitHub, allowing community inspection, reuse, and collaborative learning.
2. **Inclusive & Accessible Design**: The program features a clean, text-based command-line interface that requires minimal computing resources to run, making it accessible to institutions with limited hardware.
3. **Privacy-Respecting**: The system strictly stores non-sensitive academic mock data (student IDs, names, and general ages), avoiding any collection of private or sensitive personal identifiable information (PII).
4. **Modular & Reusable**: Built using clean OOP principles, separating logic into distinct `Student` and `Course` classes that can be easily extended or integrated into a larger framework.
